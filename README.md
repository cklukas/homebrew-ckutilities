# Homebrew tap for CK Utilities

```sh
brew install cklukas/ckutilities/ck-utilities
```

Includes the launcher, JSON View, Find, Disk Usage, Config, Markdown editor,
and local AI Chat. Builds the immutable release source with a pinned
ckVision SDK and llama.cpp.

To update: `brew update` then `brew upgrade cklukas/ckutilities/ck-utilities`.
